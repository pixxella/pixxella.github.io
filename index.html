AutoHotkey v2 Multitool & Macros

Custom AHK v2 script for fast window pinning, rapid VM toggling, memory purging, and key remapping for gaming & dev workflows. 

; ============================================================
; pxlz.pro AutoHotkey v2 Window & VM Manager Utility
; Author: pixxella (nPixel) | License: MIT
; ============================================================
#Requires AutoHotkey v2.0
SetWorkingDir A_ScriptDir

; Win + Shift + T -> Toggle Always-On-Top for active window
#+t:: {
    WinSetAlwaysOnTop -1, "A"
    ToolTip("📌 Window Pin Toggled!")
    SetTimer () => ToolTip(), -1500
}

; Win + Shift + V -> Instant Focus / Launch VMware Workstation
#+v:: {
    if WinExist("ahk_exe vmware.exe") {
        WinActivate
    } else {
        Run("C:\Program Files (x86)\VMware\VMware Workstation\vmware.exe")
    }
}

; Win + Shift + R -> Fast RAM Working Set Purge
#+r:: {
    DllCall("psapi.dll\EmptyWorkingSet", "Ptr", -1)
    ToolTip("⚡ System Memory Trimmed!")
    SetTimer () => ToolTip(), -1500
}

VMware & Hypervisor Latency Tweaks

Optimized VMX parameter configurations for VMware Workstation. Reduces input latency, disables hypervisor throttling, and optimizes 3D acceleration. 

# ============================================================
# pxlz.pro VMX Hypervisor Optimization Flags
# ============================================================
mks.enable3d = "TRUE"
mks.gl.allowDirectMemoryAccess = "TRUE"
svga.vramSize = "268435456"
isolation.tools.copy.disable = "FALSE"
isolation.tools.paste.disable = "FALSE"
mainMem.useNamedFile = "FALSE"
MemTrimRate = "0"
sched.mem.pshare.enable = "FALSE"
prefvmx.minVmMemPct = "100"
hypervisor.cpuid.v0 = "FALSE"
